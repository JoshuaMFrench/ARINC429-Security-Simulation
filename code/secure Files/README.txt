The Files Included are secure verstions of the ARINC 429 with a cryptographic signiture to prevent spoofed and replayed packets
To run the code in one terminal run
python secure_pilot_interface.py
and in the other termal run
python secure_aoa.py & secure_FMS.py (to add the replay attack add & python 40Bmal_FMS.py)
